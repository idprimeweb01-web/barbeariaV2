====================================================================
 BarberOS — FLUXO DETALHADO DE TELAS E AÇÕES (manual de uso)
 Gerado em 19/07/2026 a partir da leitura de todos os templates/páginas
====================================================================

Como ler este documento:
- Cada tela tem: o que aparece ao abrir, e uma lista de ações (botões,
  abas, links) com o que cada uma faz.
- "Abre modal com campos: ..." significa que aparece uma janela por cima
  da tela atual com aquele formulário.
- "Ação direta" significa que o clique já executa a ação (às vezes com
  uma caixa de confirmação do tipo "Tem certeza?"), sem abrir formulário.
- O documento está dividido em 5 partes: Portas de entrada (login/
  cadastro/agendamento público), Gestor, Funcionário (Barbeiro), Cliente
  e Super Admin (dono da plataforma).


====================================================================
 PARTE 0 — PORTAS DE ENTRADA (antes de logar)
====================================================================

--------------------------------------------------------------------
TELA DE ACESSO DA EQUIPE — /entrar
--------------------------------------------------------------------
Usada por: Gestor, Funcionário (Barbeiro) e Super Admin — é a MESMA tela
para os três; o sistema decide para onde mandar o usuário depois do
login, de acordo com o perfil cadastrado no banco (não existe seleção
manual de perfil na tela).

Ao abrir: logo "BarberOS", selo "Acesso da Equipe", e um formulário com:
- Campo E-mail
- Campo Senha (com botão de olho para mostrar/ocultar o texto digitado)
- Checkbox "Lembrar-me" (mantém a sessão por 30 dias; sem marcar, expira
  ao fechar o navegador)
- Link "Esqueci a senha" → leva para /esqueci-senha
- Botão "ENTRAR"

Ações disponíveis:
- Botão "ENTRAR": valida e-mail e senha preenchidos, envia para o
  servidor. Se as credenciais estiverem corretas, redireciona
  automaticamente conforme o perfil do usuário:
    - gestor      → /gestor/dashboard
    - barbeiro    → /barbeiro/dashboard
    - super_admin → /super/dashboard
  Se a conta pertencer a um CLIENTE, mostra erro explicando que essa
  entrada é só para equipe e que clientes acessam pelo link do
  estabelecimento. Se a conta estiver desativada, mostra erro específico.
  Se as credenciais estiverem erradas, mostra "Credenciais inválidas."
- Link "Esqueci a senha": vai para a tela de recuperação de senha da
  equipe (/esqueci-senha) — pede e-mail e telefone, gera uma solicitação
  que aparece na tela "Solicitações de Senha" do Super Admin/Gestor.

--------------------------------------------------------------------
AGENDAMENTO PÚBLICO — /b/<slug-da-barbearia>
--------------------------------------------------------------------
Usada por: qualquer visitante, SEM precisar estar logado. É o link que a
barbearia divulga (Instagram, WhatsApp etc.). Depois de finalizar o
agendamento, o site sugere criar uma conta para acompanhar o histórico.
É uma tela cheia (não é a mesma coisa que o SPA do cliente logado) — um
wizard próprio de 5 passos + tela de sucesso, com barra de progresso
numerada (1-2-3-4-5) no topo.

PASSO 1 — Identificação:
- Campo Telefone* (com máscara automática)
- Campo Seu nome*
- Campo E-mail (opcional)
- Botão "Próximo →": valida telefone e nome preenchidos e avança
- Abaixo do formulário: "já tem cadastro?" com dois botões "Entrar" e
  "Criar conta", que levam para /b/<slug>/entrar e /b/<slug>/cadastro
  (ou seja, dá pra pular o fluxo de convidado e logar direto)

PASSO 2 — Serviços:
- Lista de serviços (nome, duração, preço, descrição) — seleção múltipla,
  clicar marca/desmarca um serviço
- Resumo dinâmico no rodapé: "N serviço(s) · X min · R$ Y"
- Botão "← Voltar" e botão "Próximo →" (exige pelo menos 1 serviço
  selecionado)

PASSO 3 — Profissional:
- Lista de barbeiros que atendem TODOS os serviços escolhidos (foto/
  inicial, nome, bio)
- Se houver só 1 profissional elegível, o sistema pula esse passo
  automaticamente e já segue pro passo 4
- Botão "← Voltar" e "Próximo →"

PASSO 4 — Data & Horário:
- Campo de data (não permite escolher data passada nem além do limite de
  antecedência configurado pela barbearia)
- Ao escolher a data, carrega automaticamente a grade de horários livres
  daquele profissional para a duração total escolhida
- Se não houver horário livre naquele dia, mostra aviso sugerindo tentar
  outro dia
- Botão "← Voltar" e "Próximo →" (exige um horário selecionado)

PASSO 5 — Confirmar:
- Resumo do agendamento (serviços, profissional, data/hora, valor total)
- Escolha da forma de pagamento: "Pagar no local" (padrão) ou "PIX" (só
  aparece se a barbearia tiver a feature de PIX integrado ativada)
- Botão "← Voltar" e botão "Confirmar agendamento"

TELA DE SUCESSO (passo 6):
- Ícone de comemoração + "Agendamento confirmado!"
- Se o pagamento escolhido foi PIX: mostra QR Code, código "copia e
  cola" com botão "📋 Copiar código PIX", e uma área para anexar o
  comprovante (upload de imagem até 5 MB) com botão "Enviar comprovante"
  — depois de enviado, mostra confirmação "Comprovante enviado! O gestor
  irá confirmar em breve."
- Botão "Fazer novo agendamento": reinicia o wizard do zero (volta pro
  passo 1)
- Link "Crie sua conta" ao final, sugerindo cadastro para acompanhar
  agendamentos e benefícios pelo painel do cliente

--------------------------------------------------------------------
LOGIN DO CLIENTE — /b/<slug>/entrar
--------------------------------------------------------------------
Ao abrir: logo/nome da barbearia + formulário com Campo E-mail, Campo
Senha (com botão de mostrar/ocultar), checkbox "Lembrar-me" (vem marcado
por padrão), link "Esqueci minha senha" (→ /b/<slug>/esqueci-senha).

Ações disponíveis:
- Botão "ENTRAR": valida e envia; se sucesso, redireciona para
  /cliente/dashboard. Se a conta já estiver logada como cliente,
  redireciona direto pro dashboard sem pedir login de novo.
- Link "Cadastre-se" no rodapé: leva para /b/<slug>/cadastro.

--------------------------------------------------------------------
CADASTRO DO CLIENTE — /b/<slug>/cadastro
--------------------------------------------------------------------
Ao abrir: formulário com Nome completo*, Telefone (WhatsApp)* (com
máscara automática "(XX) XXXXX-XXXX"), E-mail* (com dica: "não tem
e-mail? pode inventar um só pra login"), Senha* (mín. 8 caracteres),
Confirmar senha*.

Ações disponíveis:
- Botão "CRIAR CONTA": valida todos os campos (nome, telefone, e-mail em
  formato válido, senha com 8+ caracteres, confirmação igual à senha).
  Se já existir conta com aquele e-mail, ou se aquele telefone já tiver
  dono, mostra erro específico. Em caso de sucesso, cria a conta, já loga
  automaticamente e redireciona para /cliente/dashboard.
- Link "Entrar" no rodapé: volta para /b/<slug>/entrar (para quem já tem
  conta).


====================================================================
 PARTE 1 — ÁREA DO GESTOR (perfil "gestor" / "super_admin")
====================================================================

Depois de logar em /entrar, o gestor cai em /gestor/dashboard. A tela
inteira tem uma barra lateral (sidebar) fixa à esquerda com os seguintes
itens de menu, nesta ordem:

  Dashboard
  Agenda            (expande em: Aguardando Transferência, Planos*,
                      Cupons*, VIP*)
  Serviços
  Produtos          (expande em: Vendas*)
  Pessoas           (expande em: Funcionários, Clientes)
  Relatórios        (expande em: Auditoria)
  Solicitações      (expande em: Solicitações de Plano*, Pedidos de
                      Compra*, Solicitações de Senha, Dúvidas do Cliente)
  Configurações     (expande em: Meu Perfil, Config. PIX, Webhook/n8n,
                      Bot WhatsApp, Aparência)

(*) Alguns subitens só aparecem se a funcionalidade correspondente
estiver ativada para aquela barbearia (ex.: "Planos" só aparece se o
recurso de planos de assinatura estiver ligado).

A seguir, o detalhamento de cada tela, na ordem em que aparecem no menu.

--------------------------------------------------------------------
DASHBOARD — /gestor/dashboard
--------------------------------------------------------------------
Ao abrir: a página mostra "Carregando…" e, assim que os dados chegam,
exibe 4 cards principais em grade e, abaixo, uma linha com 2 blocos
maiores.

Cards principais:
- "Agendamentos Hoje": número de agendamentos do dia (status agendado) e,
  como subtexto, quantos já foram concluídos hoje.
- "Top Serviços do Mês": lista dos 3 serviços mais vendidos no mês, com
  posição (1., 2., 3.), nome e quantidade (ex: "2×"). Se não houver nenhum
  serviço registrado, mostra "Nenhum serviço ainda".
- "PIX Pendentes": card condicional — só aparece se houver pelo menos 1
  pagamento PIX pendente de aprovação. Mostra a quantidade de PIX
  pendentes.
- "Receita do Mês": valor total faturado no mês + subtexto com o ticket
  médio.

Linha secundária (2 blocos lado a lado, empilham em telas estreitas):
- "Receita — últimos 7 dias": gráfico de barras com a receita diária dos
  últimos 7 dias, somando apenas agendamentos concluídos. Tooltip mostra
  o valor formatado em reais ao passar o mouse.
- "Estoque Crítico": lista até 8 produtos com estoque abaixo do mínimo,
  nome do produto e quantidade em destaque (vermelho). Se não houver
  nenhum alerta, mostra "Sem alertas ✓".

Ações disponíveis:
- Botão "Ver na Agenda →" (dentro do card PIX Pendentes, só existe quando
  o card está visível): navega para a tela Agenda.
- Não há outros botões de ação nesta tela — é uma tela somente de leitura
  (nenhum CRUD, nenhum modal). Todo o resto é informativo.

--------------------------------------------------------------------
AGENDA — /gestor/agenda
--------------------------------------------------------------------
Ao abrir: mostra uma barra de ferramentas no topo e, abaixo, uma tabela
dos agendamentos do dia selecionado (o dia atual, por padrão).

Barra de ferramentas:
- Setas "‹" e "›": navegam um dia para trás/frente, recarregando a
  tabela.
- Rótulo central com a data por extenso.
- Campo de data (calendário): permite pular direto para qualquer dia.
- Select "Barbeiro": filtra por profissional ("Todos barbeiros" + lista
  dos ativos).
- Select "Status": filtra por status (Todos / Agendado / Ag. comprovante
  / Ag. aprovação / Ag. PIX (legado) / Em atendimento / Concluído /
  Cancelado).
- Botão "+ Agendar": abre o modal "Novo Agendamento".

Tabela (Hora, Status, Cliente/Serviço, Barbeiro, Valor, Ações):
- Cada linha mostra hora, um badge colorido de status, nome do cliente
  com o serviço logo abaixo, nome do barbeiro, valor total em destaque.
- Se não houver nenhum agendamento no filtro/dia atual, mostra "Nenhum
  agendamento para este dia."
- Paginação (Anterior/Próxima + "Página X de Y") aparece só quando há
  resultados.

Botões de ação por linha (aparecem conforme o status atual do
agendamento):
- "✓ PIX" (se aguardando aprovação/comprovante/pagamento): abre o modal
  "Aprovar Pagamento PIX".
- "▶ Iniciar" (se agendado): ação direta — marca como iniciado, toast
  "Atendimento iniciado." e recarrega a tabela.
- "✓ Concluir" (se agendado ou em atendimento): ação direta — marca como
  concluído, toast "Atendimento concluído.".
- "✕ Cancelar" (se não cancelado/concluído): abre o modal "Cancelar
  Agendamento".

Modal "Novo Agendamento": Barbeiro* (select — ao escolher, carrega os
serviços que ele realiza), Serviço* (select, mostra duração e preço),
Nome do cliente*, Telefone*, Data e hora*. Botões "Cancelar"/"Agendar".

Modal "Aprovar Pagamento PIX": mostra cliente e valor. Se o cliente ainda
não enviou comprovante, mostra aviso; se enviou, mostra a imagem do
comprovante (clicável para tamanho original). Botões "Cancelar" e "✓
Confirmar Aprovação".

Modal "Cancelar Agendamento": mostra cliente/serviço (leitura), campo
"Motivo (opcional)". Botões "Voltar" e "Cancelar agendamento" (ação
destrutiva).

--------------------------------------------------------------------
AGUARDANDO TRANSFERÊNCIA — /gestor/transferencias  (submenu de Agenda)
--------------------------------------------------------------------
Ao abrir: título e texto explicativo ("Agendamentos sem profissional
definido — barbeiro desativado ou transferência em aberto. Transfira
para um dos profissionais elegíveis abaixo."). Abaixo, lista de cartões,
um por agendamento pendente, cada um com data/hora, nome do cliente e
lista de serviços.

Estado vazio: "Nenhum agendamento aguardando transferência."

Ações disponíveis (por cartão):
- Se há barbeiros elegíveis para aquele horário/serviço: select "escolha
  o profissional" + botão "Transferir" — ação direta que reatribui o
  agendamento, toast "Agendamento transferido." e o cartão some da lista.
- Se NÃO há profissional elegível: mostra apenas o texto "Nenhum
  profissional elegível para este horário." (sem ação possível).
- Não há modais — a transferência é feita direto no cartão.

--------------------------------------------------------------------
PLANOS — /gestor/planos  (submenu de Agenda)
--------------------------------------------------------------------
Ao abrir: tabela (Nome, Preço, Serviços, Barbeiro, Clientes, Status,
Ações). Estado vazio: "Nenhum plano cadastrado." Botão "+ Novo Plano".

Ações disponíveis:
- Botão "+ Novo Plano": abre modal com Nome, Preço mensal (R$),
  Expiração (dias), Descrição (opcional), lista de checkboxes de
  "Serviços incluídos" (cada um com limite mensal numérico ou toggle "∞
  ilimitado"), toggle "Plano ativo". Ao criar, o campo "Barbeiro
  responsável" fica oculto (só aparece na edição). Botões
  "Cancelar"/"Salvar".
- Ícone "✏️ Editar": mesmo modal, título "Editar Plano", já preenchido,
  mostrando também "Barbeiro responsável por este plano" (select).
- Ícone "👥 Assinantes" / clique no número de clientes: abre modal
  "Assinantes — <nome do plano>" listando clientes assinados (Cliente,
  Telefone, Desde, Status). Se não há assinantes ativos, mostra "Nenhum"
  (sem link).
- Ícone "🙈/👁️ Inativar/Ativar": ação direta que alterna o status do
  plano.
- Ícone "🗑️ Deletar": confirmação ("Deletar este plano permanentemente?")
  e exclui.

--------------------------------------------------------------------
CUPONS — /gestor/cupons  (submenu de Agenda)
--------------------------------------------------------------------
Ao abrir: tabela (Nome, Código, Tipo, Valor, Validade, Usos, Status,
Ações), com paginação (50/página). Botão "+ Cupom".

Ações disponíveis:
- Botão "+ Cupom": abre modal com Nome*, Código* (forçado maiúsculo),
  Tipo* (Percentual/Valor Fixo), Valor*, Data de Expiração*, Quantidade
  Máxima de Utilizações (vazio = ilimitado), Serviços (rádio: Nenhum /
  Todos / Selecionar quais — revela checkboxes), Produtos (mesma lógica).
  Toggle "Cupom ativo" só aparece na edição. Botões "Cancelar"/"Salvar".
- Botão "Editar": mesmo modal, preenchido, com o toggle "ativo" visível.
- Botão "Relatório": abre modal mostrando status, expiração, usos (com
  máximo se houver), usos restantes, restrição de serviços/produtos,
  total já descontado, e tabela de cada uso individual (Cliente, Quando,
  Valor Original, Desconto, Valor Final). Se ninguém usou: "Ninguém usou
  este cupom ainda."
- Botão "Remover": confirmação ("Desativar o cupom '<nome>'?") e
  desativa.

--------------------------------------------------------------------
VIP — /gestor/vip  (submenu de Agenda)
--------------------------------------------------------------------
Ao abrir: duas tabelas — "Níveis VIP" (Nível, Brinde, Tipo, Valor, Modo
Brinde [toggle inline], Status, Ações) e, abaixo, "Clientes VIP"
(Cliente, Nível atual, Meses consecutivos, Próxima renovação, Ações).
Botão "+ Novo Nível".

Ações disponíveis:
- Botão "+ Novo Nível": abre modal com Nível (número), Nome/descrição do
  brinde, Tipo (Físico/Desconto — "Desconto" revela campo "Valor do
  desconto"), toggle "Modo Brinde ativo", toggle "Nível ativo". Botões
  "Cancelar"/"Salvar".
- Ícone "✏️ Editar": mesmo modal preenchido.
- Ícone "👁️ Ver": modal somente leitura com os detalhes do nível.
- Toggle inline "Modo Brinde" (na linha da tabela): liga/desliga o
  resgate de brinde daquele nível sem abrir modal.
- Ícone "🗑️ Deletar": confirmação e exclui o nível.
- Na tabela de Clientes VIP, ícone "📜 Histórico": abre modal "Histórico
  VIP — <nome>" com data + descrição de cada evento. Sem histórico: "Sem
  histórico registrado."

--------------------------------------------------------------------
SERVIÇOS — /gestor/servicos
--------------------------------------------------------------------
Ao abrir: cabeçalho "Serviços" + botão "+ Serviço", e tabela (Nome,
Descrição, Duração, Preço, Status, Ações). Estado vazio: "Nenhum serviço
cadastrado."

Ações disponíveis:
- Botão "+ Serviço": abre modal "Novo Serviço" vazio.
- Botão "Editar": mesmo modal em modo edição, pré-preenchido.
- Botão "Remover": confirmação ("Desativar 'X'?") e desativa (não é
  exclusão real — o serviço fica "Inativo" e some das opções de novo
  agendamento).

Modal Novo/Editar Serviço: Nome*, Descrição (textarea), Duração
(minutos)* (mín. 5), Preço (R$)*. Campo "Serviço ativo" (checkbox) só
aparece no modo edição. Botões "Cancelar"/"Salvar".

--------------------------------------------------------------------
PRODUTOS — /gestor/produtos
--------------------------------------------------------------------
Ao abrir: 3 abas no topo — "Produtos" (padrão), "Categorias" e
"Movimentações".

Aba "Produtos": cabeçalho + botão "+ Produto". Tabela (Foto, Nome,
Categoria, Marca, Preço, Margem, Estoque, Status, Ações). Estoque: badge
vermelho "Zerado" se 0, badge laranja com quantidade + mínimo se abaixo
do mínimo, ou número cinza se normal. Ações por linha: "Editar" e
"Estoque" sempre; "Remover" só se ativo. Estado vazio: "Nenhum produto
cadastrado."

Aba "Categorias": cabeçalho + botão "+ Categoria". Tabela (Nome, Status,
Ações): "Editar" sempre, "Desativar" só se ativa. Estado vazio: "Nenhuma
categoria cadastrada."

Aba "Movimentações": cabeçalho + botão "+ Nova movimentação". Tabela
(Data, Produto, Tipo, Quantidade, Estoque após, Motivo, Usuário) com
badge de tipo (Entrada/verde, Saída venda/vermelho, Saída uso/vermelho,
Ajuste/cinza) e paginação. Estado vazio: "Nenhuma movimentação
registrada."

Ações/Modais:
- "+ Produto"/"Editar": modal com Nome*, Categoria (select), Marca,
  Preço de venda*, Custo unitário, Estoque inicial (só ao criar), Estoque
  mínimo, Código de barras, Foto (upload). "Produto ativo" só na edição.
- Botão "Estoque": modal "Ajustar Estoque" com Estoque atual (leitura),
  Quantidade a ajustar (+/-), Motivo (opcional). Botão "Aplicar".
- Botão "Remover": modal de confirmação "Desativar produto? Não aparecerá
  mais para novos atendimentos." (soft-delete).
- "+ Categoria"/"Editar" categoria: modal com campo único Nome*.
- "Desativar" categoria: confirmação via popup do navegador, sem modal.
- "+ Nova movimentação": modal com Produto* (select, mostra estoque
  atual), Tipo* (Entrada/Saída-venda/Saída-uso/Ajuste — só "Ajuste"
  aceita valor negativo), Quantidade*, Motivo* obrigatório.

--------------------------------------------------------------------
VENDAS — /gestor/vendas  (submenu de Produtos)
--------------------------------------------------------------------
Ao abrir: cabeçalho + botão "+ Nova venda". Filtro por data (campo de
data + botão "Ver todas"). Tabela (Data, Cliente, Profissional, Itens,
Método, Total, Status, Ações). Estado vazio: "Nenhuma venda encontrada."

Ações disponíveis:
- Filtro de data: recarrega a lista automaticamente; "Ver todas" limpa.
- Botão "Cancelar" (só vendas concluídas): confirmação ("Cancelar esta
  venda? O estoque será devolvido.") — ação direta, devolve o estoque.
- Botão "+ Nova venda": abre modal "Nova Venda".

Modal "Nova Venda": campo de busca de produto (nome/código de barras —
lista suspensa de resultados clicáveis), lista de itens adicionados (com
botões "−"/"+"/"×" por item, subtotal), total calculado automaticamente,
Cliente (opcional, texto livre), Profissional vendedor (opcional,
select), Método de pagamento* (PIX/Dinheiro/Cartão). Botão "Finalizar
venda" (exige ao menos 1 item) — registra a venda e dá baixa no estoque.

--------------------------------------------------------------------
FUNCIONÁRIOS — /gestor/barbeiros  (submenu de Pessoas)
--------------------------------------------------------------------
Ao abrir: cabeçalho "Equipe" + botão "+ Funcionário". Tabela (Foto, Nome,
Email, Telefone [+ ícone 📲 WhatsApp se houver], Comissão, Status,
Ações). Estado vazio: "Nenhum funcionário cadastrado."

Ações por linha:
- "Editar": abre modal Novo/Editar Funcionário pré-preenchido (busca
  também os serviços que ele já realiza, para marcar os checkboxes).
- "Agenda": abre modal "Configurar Agenda" desse funcionário.
- "Remover": confirmação ("Desativar 'X'?"). Se NÃO tem agendamentos
  futuros, desativa direto. Se TEM, o sistema recusa a desativação
  simples e abre automaticamente o modal "Agendamentos futuros" para
  resolver isso antes.

Modal Novo/Editar Funcionário: Nome*, E-mail, Telefone*, Senha* (mín. 6 —
só obrigatória/visível ao CRIAR), Comissão (%) (0-100), Bio, e lista de
checkboxes "Serviços que realiza" (nome + preço).

Modal "Configurar Agenda — <Nome>":
- Seção "Horário de Trabalho": Abertura, Fechamento, Intervalo entre
  slots (15/20/30/45/60 min), toggle "Loja aberta", toggle "Barbeiro pode
  editar horário" (libera a tela própria dele). Botão "Salvar horário".
- Seção "Pausas/Intervalos": lista de pausas cadastradas (com botão "✕"
  Remover, confirmação "Remover esta pausa?"). Formulário para adicionar
  nova pausa: Início, Fim, Descrição, botão "+ Pausa".

Modal "Agendamentos futuros de <Nome>" (só abre automaticamente, sem
botão manual, quando a desativação encontra agendamentos futuros):
- Lista de agendamentos futuros, cada um com select "Transferir para…" +
  botão "Transferir" (transfere aquele agendamento específico).
- Botão "Transferir restantes p/ mural e desativar": manda os restantes
  para o mural (outros barbeiros podem assumir) e desativa o funcionário.
- Link "Cancelar todos os agendamentos e desativar": confirmação
  ("Cancelar TODOS os agendamentos futuros restantes?"), cancela cada um
  e desativa o funcionário.

--------------------------------------------------------------------
CLIENTES — /gestor/clientes  (submenu de Pessoas)
--------------------------------------------------------------------
Ao abrir: grade de 6 cards de métricas (Total, Novos no mês, Inativos
>30d, Ticket médio, Retenção, VIP >R$500), barra de filtros, gráfico
"Novos clientes por mês", tabela paginada de clientes e, por fim, 4 cards
de "Insights".

Barra de filtros: busca por nome/telefone/e-mail (ao digitar), select de
status (Todos/Ativos/Novos/Inativos/Em risco/VIP), select de barbeiro,

2) "Planos disponíveis" (só se existir algum plano cadastrado): seletor

   limite ou "∞"). Rodapé de cada card:
   - Já assina: etiqueta "Plano atual" (sem ação).
   - Solicitação pendente: etiqueta "Aguardando aprovação" (sem ação).
   - Senão: botão "Assinar" → envia a solicitação com a forma de
     pagamento escolhida.
     - Se gerar PIX: troca para a tela de confirmação PIX (QR code,
       código copia-e-cola com botão "Copiar código", upload de
       comprovante com botão "Enviar comprovante", confirmação de envio,
       botão "Voltar para meus planos").
     - Senão: notificação "Solicitação enviada! Aguarde a aprovação do
       estabelecimento."

3) "Histórico de solicitações" (só se houver alguma): tabela (Plano,
   Valor, Forma de pagamento, Data, Status: Pendente/Aprovado/Rejeitado).

Ações disponíveis:
- Botão "Cancelar" em cada assinatura ativa: confirmação ("Cancelar esta
  assinatura?") — cancela e notifica "Assinatura cancelada."
- Botão "Assinar": inicia o fluxo de solicitação (ver acima).
- Na tela de confirmação PIX: "Copiar código", "Enviar comprovante",
  "Voltar para meus planos".

AGENDAR — /cliente/agendar
--------------------------------------------------------------------
Ao abrir: spinner, depois um aviso fixo no topo: se o cliente tem plano
ativo, mostra "Plano [Nome] ativo — mostrando só os serviços incluídos no
plano (N disponíveis)" (já filtra o passo 1); senão, "Sem plano ativo —
todos os serviços disponíveis para agendamento avulso."

Wizard de até 5 etapas com indicador de progresso no topo (some no passo
5). Clicar numa etapa já concluída no indicador volta direto pra ela.

ETAPA 1 — Serviço(s): grid de cards de serviço (nome, duração, preço),
seleção múltipla por clique (marca/desmarca). Resumo no rodapé
(quantidade, duração total, valor total) assim que 1+ é selecionado.
Botão "Continuar (N) →" busca os profissionais que atendem TODOS os
serviços escolhidos e avança. Vazio: "Nenhum serviço disponível para o
seu plano".

ETAPA 2 — Profissional: botão "← Voltar". Grid de cards de barbeiro
(avatar, nome, especialidade). Clicar seleciona e avança automaticamente
para a Etapa 3 (já dispara a busca de horários). Vazio: "Nenhum
profissional disponível para este serviço".

ETAPA 3 — Data e Hora: botão "← Voltar". Campo de data (não permite
passado), nome do profissional ao lado. Grid de horários disponíveis
(busca automática ao trocar a data). Vazio: mensagem específica de
indisponibilidade ou "Nenhum horário disponível nesta data". Clicar num
horário seleciona e avança automaticamente para a Etapa 4.

ETAPA 4 — Confirmar: botão "← Voltar". Resumo (serviços com preço,
Profissional, Data, Hora, Valor total, Duração total). Formulário: Forma
de pagamento (No local/PIX [se ativo]/Cartão/Dinheiro), Cupom (opcional,
maiúsculo automático), Observação (opcional). Botão "Confirmar
agendamento":
- Se gerar PIX → avança para a Etapa 5.
- Senão → notificação "Agendamento criado com sucesso!" e navega direto
  para /cliente/historico.

ETAPA 5 — Pagamento PIX (só se pagamento online): QR code, código
copia-e-cola com botão "Copiar código", upload de comprovante (JPEG/PNG
até 5 MB) com botão "Enviar comprovante" (confirmação visual após
enviado). Botão final "Ir para meus agendamentos" → /cliente/historico.

   - Se gerar PIX → tela de confirmação PIX (QR code, "Copiar código",

   - Senão → notificação de sucesso e o carrinho esvazia automaticamente.

- Na tela PIX: "Copiar código", "Enviar comprovante", "Voltar para a

Ações disponíveis:

  personalizada, Segmento (select — "troca só os rótulos, não reajusta
  features já ligadas"), e os mesmos campos de Endereço/Contato do
  cadastro. Botões "Cancelar"/"Salvar" (se o Segmento mudou, dispara uma
  segunda requisição específica para atualizá-lo).
- Link "Ver site" (por linha): abre a página pública do estabelecimento
  em nova aba.
- Botão "Desativar" (só em ativas): confirmação nativa ("Desativar
  'NOME'? Todos os usuários deste estabelecimento também serão
  desativados.") — ação direta.
- Botão "Ativar" (só em inativas, verde): ação direta, sem confirmação.
